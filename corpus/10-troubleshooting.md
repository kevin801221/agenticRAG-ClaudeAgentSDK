# 常見問題排除

## Hook 相關

**寫了 hook 但完全沒跑**
最常見原因是只把腳本放進 `.claude/hooks/`，沒有在 `settings.json` 的 `hooks` 欄位註冊。
第二常見是改了設定沒重開 session。

**PreToolUse 沒有擋住**
exit code 要是 `2` 才會阻止。`exit 1` 只會記錄錯誤，工具照跑。

**hook 腳本權限不足**
記得 `chmod +x`。

## Agent SDK 相關

**`allowed_tools` 寫了工具名還是被擋**
MCP 工具的完整名稱是 `mcp__<server>__<tool>`，要用完整名稱。

**設了 `tools=[]` 之後 MCP 工具也不見了**
不會。`tools` 只管內建工具，MCP 工具走 `mcp_servers` 參數，兩者獨立。

**agent 完全不呼叫工具**
通常是工具的 `description` 寫太含糊，或 system prompt 沒有明講要用工具。
把描述寫具體，並在 prompt 裡說「不要自己編，要用工具查」。

**平行工具呼叫的結果對錯卡片**
模型會一次發多個工具呼叫，結果回來的順序不保證。
要用 `tool_use_id` 對應，不能用遞增的計數器。

**每次呼叫都很慢**
`query()` 每次都會重新開一個 CLI 子行程。多輪對話改用 `ClaudeSDKClient`，
連線開一次就好。

## 檢索相關

**中文查什麼都查不到**
檢查斷詞器有沒有接上，以及索引端和查詢端是不是用同一套。

**HyDE 效果很差**
HyDE 需要向量檢索才有意義。如果向量不可用而退回關鍵字比對，
等於拿一段長文去做關鍵字搜尋，結果會很怪。

**檢索結果都在講同一件事**
用 MMR 去重。相關度高不代表資訊量大。

**要不要裝向量資料庫**
先量再裝。幾千到幾萬個片段，用 numpy 暴力算 cosine 只要零點幾毫秒，
而把問題轉成向量要好幾毫秒 —— 檢索根本不是瓶頸。
十萬筆以上、需要增量更新、或需要 metadata 過濾時才划算。
